# Instagram Autopilot: weekly run

1. Get the owner's autopilot repo (the copy of the template that has `autopilot/brand.json` filled in)
   with push access: use a GitHub attach/add-repo tool if you have one, otherwise `git clone`.
   If you don't know which repo, ask. If `autopilot/brand.json` doesn't exist, the page isn't set up:
   switch to the setup skill.
2. Open `autopilot/RUNBOOK.md` and follow it exactly, from step 0 to step 6.
3. Reply with the summary from step 6 of the runbook.

Rules that always apply: nothing paid; never invent statistics, reviews, client names or results;
use only the prices in brand.json; never ask for or handle the Instagram token.
